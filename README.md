# BYR Next 2.1

Build Your Restaurant 의 신규 빌드입니다. 기존 HTML/Vanilla JS 앱은 건드리지 않고, 별도 Electron 프로젝트로 처음부터 만들었습니다.
기존 앱에서 만든 작업물(JSON)은 그대로 불러와 Three.js 장면으로 바꿉니다.

## GitHub 에 올려서 exe 받기 (설치 없이)

1. 이 폴더 전체를 GitHub 저장소(새 저장소 또는 기존 저장소의 별도 브랜치)에 올립니다. `.github/workflows/build.yml` 이 같이 올라가야 합니다.
2. 올리면 Actions 가 자동으로 돕니다.
   - `smoke`: 리눅스에서 진짜 Electron 으로 앱을 켜고, 샘플을 불러오고, 스타일 6가지를 바꿔 본 뒤 오류가 없으면 통과.
   - `windows`: 윈도우 포터블 exe 를 만들어 **Artifacts → BYR-Next-windows** 에 올립니다. 내려받아 바로 실행.
   - `android`: 안드로이드 APK 를 만들어 **Artifacts → BYR-Next-android** 에 올립니다. 화면 파일이 앱 안에 들어 있어 인터넷 없이도 열립니다(AI · 계정 기능만 인터넷 필요). 저장 · 내보내기는 공유 창으로 내 파일 · 드라이브 · 메일에 보냅니다.
3. 내 PC 에서 직접 돌리고 싶을 때만 아래 "실행"을 따릅니다.

## 실행

```bash
npm install     # Electron 설치 + Three.js 를 renderer/vendor 로 복사(postinstall)
npm start       # 앱 실행
npm run dist    # (선택) Windows 포터블 exe 만들기
```

- Node.js 20 이상이 필요합니다.
- `renderer/vendor/three` 에 Three.js r170 과 필요한 모듈이 이미 들어 있어, 실행 중에는 인터넷이 필요 없습니다(CDN 없음).
- Electron 없이 화면만 확인하려면 `renderer` 폴더를 아무 정적 서버로 띄우면 됩니다: `npx serve renderer` 또는 `python -m http.server -d renderer 8770`.

## 기존 작업물 불러오기

1. 기존 앱에서 **내보내기 → JSON** 으로 프로젝트를 저장합니다.
2. 새 앱에서 **파일 메뉴(폴더 아이콘) → 기존 앱 작업물 가져오기** 를 누르거나, JSON 파일을 화면에 끌어다 놓습니다.

받을 수 있는 형태 (`legacy.js` 의 `findLegacyProjects`):

| 입력 | 예 |
| --- | --- |
| 프로젝트 객체 | 기존 앱의 JSON 내보내기 파일 |
| Supabase `projects` 행 | `{ "id": "...", "name": "...", "data": { ... } }` 또는 그 배열 (REST 응답 그대로) |
| 묶음 | `{ "projects": [ ... ] }` |

변환 내용 (`convertLegacy`):

| 기존 데이터 | 새 장면 |
| --- | --- |
| `walls` (x1,y1,x2,y2, 두께, 높이, 마감 색) | 문/창 자리를 뚫은 벽 메시, 모서리 채움 |
| `openings` (문 · 창 · 배식구, 간유리 범위) | 틀 · 유리 · 문짝 · 배식 선반 |
| `rooms` (다각형, 마감, 단 높이) | 공간별 바닥, 단 올림 |
| `items` (종류, 위치, 회전, 크기, 색, 재질, 디자인 수정 부품) | 기존 앱과 같은 형상에 PBR 재질 적용 |
| `levels` (층) | 층 선택 메뉴 |
| 조명 · 튀김기 · 레인지 | 그 자리에 SpotLight / PointLight |

아직 옮기지 않는 것: 바닥 구배(평평하게), 벽 디자인 수정(곧은 벽으로), 시트지 · 사인, 기존 앱에 올린 3D 모델(파일을 다시 가져와야 함), "내 기물"(프로젝트 파일에 형상이 없으면 상자로 표시).

새 형식은 `.byr.json` 으로 저장하며 좌표는 기존과 같은 mm 입니다.

## 렌더링

`renderer/js/main.js` 의 후처리 순서:

```
EffectComposer (MSAA 4x, HalfFloat)
 ├─ RenderPass   장면
 ├─ SSAOPass     틈새 음영: 기물과 바닥이 닿는 모서리를 어둡게
 ├─ OutputPass   ACES 톤 매핑 + sRGB
 └─ ShaderPass(FXAAShader)  가장자리 정리
```

- 재질: 전부 `MeshStandardMaterial`. 스테인리스는 metalness 0.9 + 헤어라인 거칠기 지도, 목재 · 페인트는 roughness 로 구분.
- 조명: `AmbientLight` + `DirectionalLight`(4096 그림자) + 코드로 만든 실내 환경 지도(금속 반사용).
- 기물 조명은 화면 중심에서 가까운 24개까지만 켭니다(태블릿 성능). 속성 카드에서 기물별로 켜고 끄고 밝기 · 색을 바꿉니다.

## 조작

| 동작 | 방법 |
| --- | --- |
| 화면 돌리기 / 확대 · 이동 | 한 손가락 끌기 / 두 손가락 |
| 기물 고르기 | 톡 누르기 → 오른쪽 속성 카드 |
| 기물 옮기기 | 상단 **이동** 모드에서 기물을 끌기 (10mm 단위) |
| 기물 추가 | 왼쪽 위 메뉴 → 서랍에서 고르기 |
| 외부 3D 파일 | GLB · GLTF · OBJ · FBX 를 끌어다 놓기 |
| 내보내기 | 파일 메뉴 → GLB(재질 포함) / OBJ(형상만) |

## 2D 도면 → 3D

상단 **2D · 분할 · 3D** 로 화면을 나눕니다. 분할이면 왼쪽(세로 화면은 위) 도면에서 그린 것이 오른쪽 3D 에 손을 떼기 전부터 세워집니다.

| 도구 | 방법 |
| --- | --- |
| 벽 그리기 | 점을 차례로 톡 (같은 점 한 번 더 · Esc · 오른쪽 클릭으로 끝) 또는 끌어서 한 번에. 50mm 모눈 · 기존 벽 끝점에 붙고, 거의 수평/수직이면 맞춰짐 |
| 문 · 창 · 배식구 | 도구를 고르고 벽을 톡 |
| 고르기 · 끌기 | 기물 끌기, 문/창은 벽을 따라 끌기, 벽을 고르면 파란 끝점을 끌어 늘이기(붙은 벽도 따라옴), 벽 몸통을 끌면 통째로 이동 |
| 지우기 | 도구를 고르고 톡, 또는 Delete |
| 화면 | 빈 곳 끌기 · 휠 · 두 손가락 |

벽을 고르면 속성 카드에서 길이 · 두께 · 높이 · 색 · 마감을 숫자로 바꾸고, 가운데서 나눌 수 있습니다. 문/창은 종류 · 폭 · 높이 · 바닥에서 높이 · 간유리 띠.

## 보기 스타일 (붓 아이콘)

스타일은 "보이는 방식"만 바꾸고 모델은 그대로라서, 어느 스타일에서든 그리기 · 옮기기 · 되돌리기를 계속할 수 있습니다. 저장 · GLB 내보내기는 항상 원래 PBR 재질로 나갑니다.

| 스타일 | 만드는 방법 |
| --- | --- |
| 실사 | PBR + SSAO + 그림자 + 기물 조명 |
| 카툰 | MeshToonMaterial 3단 셀 셰이딩 + 법선/깊이 외곽선 |
| 타이쿤 | 정투영(원근 없음) 미니어처 시점 + 2단 셀 + 파스텔 보정 + 색 경계에도 부드러운 선 |
| 만화 | 굵은 잉크 선(두 겹) + 손으로 그은 듯한 흔들림 + 종이 질감 |
| 클레이 | 무광 찰흙 재질 + 강한 틈새 음영 |
| 도면 | 정투영 흑백 다이어그램 |

## AI · 계정 (기존 앱 기능)

기존 앱은 Anthropic 키로 Claude 를 불러 (1) 도면 이미지 → 벽, (2) PDF 도면 읽기, (3) 현장 사진 → 기물 배치를 했습니다. 같은 지시문으로 옮겼습니다.

- 파일 메뉴 → **AI** : 키 넣기(이 기기에만 저장) · 도면 사진/PDF → 벽 · 문/창 · 고른 벽의 사진 → 기물/문/창.
- 파일 메뉴 → **기존 앱 계정에서 불러오기** : 기존 앱 "계정 · 동기화"와 같은 이메일로 로그인하면 계정 프로젝트 목록이 뜨고, 누르면 변환해서 엽니다. 계정에 저장해 둔 AI 키도 같이 받아옵니다.
- 키는 저장소 · 설정 파일에 넣지 않습니다. 앱에 들어 있는 것은 공개용(publishable) Supabase 키뿐입니다.
